# Vedic Pandit Android app

The app is the same Angular code as the website, wrapped with [Capacitor](https://capacitorjs.com)
(the same setup as Cassette.fm). GitHub builds the APK for you, so there is nothing to install on your computer.

Panchang, muhurat, mantra and granth (the full Gita) all run inside the phone, so the app works with no internet.
PanditJi gives full AI answers once you host the API and set the `API_URL` repository variable
(see [DEPLOY.md](DEPLOY.md)); until then it uses its built-in answers.

## One-time setup

1. **Create a GitHub repo** named `VedicPandit` and upload this whole folder (keep `vedic-pandit-client/android/`).
2. **Turn on the website:** repo **Settings → Pages → Source: GitHub Actions**.
   The site goes live at `https://<your-username>.github.io/VedicPandit/`.
3. **Make a signing key** (once, on any computer with Java):
   ```bash
   keytool -genkeypair -v -keystore vedicpandit-release.jks -alias vedicpandit \
     -keyalg RSA -keysize 2048 -validity 10000
   base64 -w0 vedicpandit-release.jks > keystore.b64      # on macOS: base64 -i vedicpandit-release.jks
   ```
   Add 4 secrets under **Settings → Secrets and variables → Actions → New repository secret**:
   `KEYSTORE_BASE64` (contents of keystore.b64), `KEYSTORE_PASSWORD`, `KEY_ALIAS` (`vedicpandit`), `KEY_PASSWORD`.
   Back up `vedicpandit-release.jks` somewhere safe. Every future update must be signed with it.
   You can skip this step to try the app first: the workflow then builds a test (debug) APK.
4. **Build:** push to `main`, or go to **Actions → Build Android app → Run workflow** (about 6–8 minutes).
5. **Get the APK:** this link always gives the newest one, and the website's **Get App** button uses it:
   `https://github.com/<your-username>/VedicPandit/releases/latest/download/VedicPandit.apk`

On the phone: tap **Get App** → **Download** → **Install** (allow "Install unknown apps" for the browser when asked).
Installing a newer APK updates the app.

If your repo has a different name or owner, nothing needs editing: the workflows write the right
address into `src/app/core/app-info.ts` when they build.

## What's different in the app

| | |
|---|---|
| **Works offline** | All calculations run on the phone. |
| **Location** | Pick State → District (no location permission needed). |
| **Voice guide** | Uses Android's own Hindi text-to-speech. If it isn't installed: Settings → Text-to-speech → Google Speech Services → install Hindi. |
| **Dakshina** | "Pay with UPI app" opens GPay / PhonePe / Paytm / BHIM directly with the amount filled in. |
| **Back button** | Closes PanditJi's panel or goes back a page; on the home page it sends the app to the background. |
| **No Get App button** | It hides itself inside the app. |
| **Voice input** | The mic button needs Chrome's speech recognition, which Android's in-app browser doesn't have, so it is hidden in the app for now. |

## Files

```
vedic-pandit-client/
  capacitor.config.ts                 app name, ID (com.vedicpandit.app), splash colour
  android/                            the Android project (generated by Capacitor)
    app/build.gradle                  version number + release signing (filled in by the workflow)
    app/src/main/AndroidManifest.xml  permissions: internet; finding UPI apps and the text-to-speech engine
  assets/                             icon and splash source images
                                      (regenerate: npx @capacitor/assets generate --android)
  src/app/core/app-info.ts            repo name, version, APK link, UPI ID
  src/app/core/services/native.service.ts   app vs website, Android back button
.github/workflows/android.yml         builds the APK and publishes the release
.github/workflows/deploy.yml          publishes the website to GitHub Pages
```

## Build on your own computer (optional)

Needs [Android Studio](https://developer.android.com/studio).

```bash
cd vedic-pandit-client
npm install
npx ng build
npx cap sync android
npx cap open android      # then ▶ Run in Android Studio with your phone plugged in
```

## Play Store

This setup makes an APK to share directly. The Play Store needs an `.aab`
(`./gradlew bundleRelease`) and a Google Play developer account.
